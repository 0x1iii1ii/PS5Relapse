# PS5 WebKit and Relapse Exploit
Supported firmware: 11.60, 12.00, 12.02, 12.20, 12.40, 12.60, 12.70, 13.00, 13.20, 13.40, 13.42, and 13.60.

## Usage

Run `python serve.py`, then open the printed URL on the PS5. The default payloads are stored in `payloads/` after a successful run, the ELF loader listens on port `9021`.
